# GameVoiceKey · 游戏语音按键自定义助手

> 一款全自定的全局游戏语音按键映射工具——把"语音指令"自动变成游戏里的按键操作。
> 适配所有电脑游戏：FPS / MOBA / 模拟器 / Steam / 任何 exe，全程后台静默运行。

---

## 这是什么

- 首次启动先做**麦克风 + 扬声器检测**：看得见的电平条，30 秒确认设备没问题
- 首页**主动选择「当前在玩的游戏进程」**，选完直接进编辑页开始配键
- 自动识别前台游戏进程，切换到对应的语音指令库
- 每条语音规则你说了算：触发短语、要按的键、是单击 / 长按 / 连发，自己定
- 多游戏独立配置：A 游戏的快捷键和 B 游戏的快捷键完全隔离
- 游戏内悬浮窗：打游戏时也能看到当前识别游戏 / 波形 / 最近触发的指令
- 关闭即休眠：游戏关闭瞬间语音监听自动暂停，避免桌面误触发
- 全自定热键：开 / 停 / 暂停 / 重载 / 静音麦克风
- **不装游戏插件、不改游戏内存** ——绕开所有反作弊

首次启动自带「FPS / MOBA」示例配置，立刻能试。

## 快速开始

**玩家版**：

1. 下载 `GameVoiceKey.exe`
2. 双击运行 —— 第一次启动会先弹**设备检测向导**：说句话看麦克风电平条，
   再点一下扬声器测试音（可单独测左 / 右声道），确认没问题点「开始使用」
3. 回到首页点**「选择当前游玩的游戏」**，在列表里点中你正在玩的游戏
   （没配过的话会自动建一份配置）→ 直接跳到语音按键编辑页
4. 在编辑页里加几条指令：「开枪」→ 左键、「跳跃」→ 空格，想怎么配怎么配
5. 对着耳麦说「开枪」「跳跃」→ 自动按对应键；托盘出现青绿图标代表已在后台监听

**开发者版**：

```powershell
git clone https://github.com/zlwzk/GameVoiceKey.git
cd GameVoiceKey
pip install -r requirements.txt
python launch.py
```

打包成单 exe：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
```

跑自检：

```powershell
python -m scripts.selftest
```

## 数据安全（重点）

### 1. 多用户互不干扰

用户数据固定在 `%APPDATA%\GameVoiceKey\`。Windows 上**每个登录账户有自己独立的
`%APPDATA%`**，所以同一台电脑上不同用户各存各的，配置永不串味。

程序启动时会做一次体检：如果数据目录被配到了程序目录里（会导致升级覆盖 exe
时丢数据），会自动改回默认位置并留下告警。

### 2. 软件更新不丢设置

升级的常规做法是「下载新 exe → 覆盖旧的」。因为数据不在程序目录，覆盖 exe
碰不到你的配置。在此之上还有三层保险：

| 保险 | 触发时机 | 作用 |
|---|---|---|
| 升级自动快照 | 检测到版本号变化 | 旧数据整份存进 `backups/`，随时可回滚 |
| 原子写 + `.bak` | 每次保存配置 | 任何一次写入都留下「上一版良好副本」 |
| 损坏自动恢复 | 读取到非法 json | 自动从 `.bak` 恢复，并把坏文件另存为 `.corrupt-<时间>` |

高级设置页 →「数据与备份」可以查看数据目录、手动备份、从任意快照恢复。
快照自动保留最近 8 份，多的自动清理。

### 3. 向前兼容

如果新版本加了配置项，之后又临时降级到旧版本运行，旧版本会把不认识的字段
原样保留、写回时不丢，等你再升级上去设置还在。

## 关键技术事实

- **用户数据目录**：`%APPDATA%\GameVoiceKey\`
  - `settings.json` 全局设置
  - `profiles\<game_id>.json` 每个游戏一份
  - `models\` Vosk 模型目录
  - `logs\gvk-YYYY-MM-DD.log` 日志
  - `backups\<时间戳>-<原因>\` 配置快照
- **进程扫描**：`psutil.process_iter`，默认 1.5s 一次
- **前台窗口检测**：`ctypes` 调 `GetForegroundWindow`
- **按键注入**：`pynput` 在背后调用 `SendInput`，避免触发反作弊
- **全局热键**：`keyboard` 库
- **悬浮窗**：`PySide6` 半透明 QWidget + WS_EX_TRANSPARENT
